# SkillSwap Color System

## Brand Colors (2-Color Palette)

### Primary Color
- **Hex**: `#C11C84`
- **RGB**: `rgb(193, 28, 132)`
- **RGBA (10% opacity)**: `rgba(193, 28, 132, 0.1)`
- **RGBA (25% opacity)**: `rgba(193, 28, 132, 0.25)`
- **Usage**: Primary buttons, links, active states, brand elements, icons

### Secondary Color  
- **Hex**: `#1e293b`
- **RGB**: `rgb(30, 41, 59)`
- **RGBA (10% opacity)**: `rgba(30, 41, 59, 0.1)`
- **Usage**: Text, headers, secondary buttons, dark elements

### Neutral Colors (Supporting)
- **White**: `#FFFFFF` - Backgrounds, cards
- **Light Gray**: `#F8F9FA` - Subtle backgrounds
- **Medium Gray**: `#6B7280` - Secondary text
- **Dark Gray**: `#1F2937` - Body text
- **Border Gray**: `#E2E8F0` - Borders, dividers

## Usage Guidelines

### Buttons
- **Primary Button**: Background `#C11C84`, Text `#FFFFFF`
- **Secondary Button**: Background `#1e293b`, Text `#FFFFFF`
- **Outline Button**: Border `#1e293b`, Text `#1e293b`

### Icons
- Alternate between `#C11C84` and `#1e293b`
- Use light backgrounds with 10% opacity of the icon color

### Links
- Default: `#C11C84`
- Hover: Darker shade or underline

### Status Colors (Keep Minimal)
- Success: Use primary `#C11C84` with success icon
- Error: `#DC3545` (only for errors)
- Warning: `#FFC107` (only for warnings)

## What NOT to Use
- ❌ Blue colors (`#1A73E8`, `#3B82F6`, `#BFD6FF`)
- ❌ Green colors (`#10B981`, `#D1FAE5`)
- ❌ Multiple pink shades (`#F7C5E5`, `#E03DA5`)
- ❌ Random accent colors

## Consistency Checklist
- [ ] All feature icons use primary or secondary color
- [ ] All buttons use primary or secondary color
- [ ] All step numbers/badges use primary or secondary color
- [ ] All links use primary color
- [ ] All hover states use consistent colors
- [ ] No random blue, green, or other colors
